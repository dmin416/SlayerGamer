## Early / AoT

### The beginning (tutorial ID)
- Objectives: Observe goblin; kill goblin; clear area; bonus Hobgoblin Chief
- **Rewards:** ID Create, ID Escape, 500 XP, $500, Random Skill Book

### One Style to rule them all (offered)
- **Listed reward:** personal style, 1,000,000 XP, $100,000,000  
- (Long-term / prestige style quest; not treated as instant cash-in)

### Build me a Cavalry (blacksmith)
- Forge 40 horseshoes + 120 nails
- **Rewards:** Class **Blacksmith +25 levels**, ODM gear Skill Book, 1000 XP

### Defend Trost
- Objectives: Kill titans in Trost; reseal wall; evacuate civilians  
- Bonuses: prove machines; show combat; prevent deaths; use Slayer weapon; (failed: hide Eren from Marley spies)
- **Rewards:** Title **Titan Slayer** (+25% vs titans), **Defender** perk, Machine pack [Epic], Home base unlocked, Faction base, **Technomancer's grimoire**, 100,000 XP, $5,000,000

### Hidden: Defang the nobles / Kenny
- Neutralize Kenny Ackermann / Interior Police (direct or indirect)
- **Rewards:** 1× Blueprint pack, 1,000,000 XP, $10,000, 2× Challenge Tokens

### Prevent the reactivation of the Faro Plague (Horizon challenge)
- **Rewards:** Zero Dawn Machine Blueprint Bundle, Companion Gem (Aloy), 100,000,000 XP, $4,000,000, Gacha tokens (Common) ×10, Class scroll ×2, Perk Gacha ×2, Home base unlocked

### A long road to your Apocalypse (AoT main)
- Prevent Rumbling; deal with Marley (in progress); different Nine hosts (failed)  
- Bonuses: leave hosts alive; disable wall Colossals; remove Nine; Paradis op fails; tech Eldia up
- **Rewards:** 1,000,000 XP, 1× Mythic Gacha, $10,000,000,000, **World travel unlocked**  
- Pause point / training world complete
