# Gacha Generation Rules (Slayer Gamer Style)

## Token Types
| Token | Draws From | Notes |
|---|---|---|
| **Common** | Every rarity, Poor through God-tier | The bulk of tokens. Junk-heavy. |
| **Rare** | Rare and up (Poor/Common removed) | Narrower pool, reliably useful |
| **Epic** | Epic and up | Usually opens a multi-item batch (5-12 items) |
| **Mythic** | Legendary and up | Story-shaping pulls |
| **Perk Gacha** | Perks only, any rarity | Use the perk roll below |
| **Class / Race / World / Companion Tokens** | Fixed category | Usually come as rewards or as gacha results themselves |

## Step 1: Rarity Roll (d100)

| d100 | Common Token | Rare Token | Epic Token | Mythic Token |
|---|---|---|---|---|
| Poor | 01-20 | - | - | - |
| Common | 21-55 | - | - | - |
| Uncommon | 56-70 | - | - | - |
| Rare | 71-85 | 01-55 | - | - |
| Epic | 86-94 | 56-85 | 01-60 | - |
| Legendary | 95-98 | 86-96 | 61-90 | 01-70 |
| Mythic | 99 | 97-99 | 91-99 | 71-97 |
| God-tier | 00 | 00 | 00 | 98-00 |

**Luck modifier:** add +1 to the roll per 10 points of Luck above 50, up to +15. Luck items stack on top (e.g., Daisy's Rabbit Foot +75% Luck).

## Step 2: Category Roll (d20)

| d20 | Category | Examples |
|---|---|---|
| 1-4 | **Junk / Comedy** | Pet rock, Cheez-Its, fire hydrant, fake dog poop, Queen CD |
| 5-8 | **Weapon** | Super Shotgun, Tempest revolver, Malorian 3516, Thunder Hammer |
| 9-10 | **Armor / Gear** | Nano Armor, Deadshot's Flight Exo, Batman's Utility Belt |
| 11 | **Consumable** | Super Soldier Serum, Skrewball Whiskey, Can of Whoop Ass |
| 12 | **Skill Book / Scroll** | Psionic Combat Form, Yoga, +25 Skill Scroll |
| 13 | **Perk** | Truth-Seeking Balls, Trenchcoat Effect, Little Reaper |
| 14 | **Material** | Block of Mithril, Kryptonite, Azbantium |
| 15 | **Tech / Blueprint** | Neural interface kit, energy core, fabricator schematic |
| 16 | **Vehicle / Mount** | Motorcycle token, mech frame, beast mount |
| 17 | **Companion / Pet** | Egg, contract, summon token |
| 18 | **Property / Base** | Safehouse deed, HQ module, pocket dimension seed |
| 19 | **Currency / Wealth** | Cash, precious metals, credit chits |
| 20 | **Meta Token** | Class, Race, World, or Companion token (reroll category flavor into one of these) |

## Step 3: Name the Result

Pick or invent one concrete item that fits **rarity + category**. Do not upgrade rarity after the roll. Comedy junk stays junk even on a high rarity token if the category hit Junk/Comedy — unless the player spends a token type that already excluded Poor/Common.

**Epic/Mythic batches:** Epic tokens often grant **5–12** related items at the rolled rarity floor. Mythic pulls may be single story-shaping awards or a small set. Do not invent exact lists without rolling or player choice.

## Perk Gacha

When the token is **Perk Gacha**, or Step 2 lands on Perk:

1. Roll rarity with the same table as the token type (or Common-token table if unspecified).
2. Name a perk that fits that rarity (minor convenience → campaign-defining).
3. Perks do not automatically spend Tribute; Eternal Cycle Tribute perks are a separate track.

## Restrictions

- Do not auto-apply gacha results mid-prose without the player spending a token.
- World / Class / Race / Companion tokens from gacha are **received**, not auto-activated.
- Keep gacha awards distinct from challenge completion reward lists and kill-loot boxes.
